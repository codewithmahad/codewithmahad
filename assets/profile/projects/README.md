# Project marks

These transparent SVG marks accompany the completed projects in the profile. They are generated by [project-marks.mjs](../../../scripts/profile/project-marks.mjs), called from the normal artwork build.

| Mark | Design |
| :--- | :--- |
| `derivify-{light,dark}.svg` | An outlined partial-derivative glyph with a rising blue curve, reflecting the symbolic differentiation engine |
| `quizzler-{light,dark}.svg` | A flat Q monogram with a checked answer, reflecting the quiz state and feedback |

Derivify uses outlined Inter lettering and original curve geometry. The font and its notice are retained in [source/](../source/). Quizzler's Q contour comes from the app's own [launcher vector](https://github.com/codewithmahad/Quizzler-App/blob/master/app/src/main/res/drawable/ic_launcher_foreground.xml), redrawn with a restrained palette and an original check stroke.

Both designs have light and dark variants, with no image background, badge frame, external font, or remote image dependency. DeployLatch retains its existing project logo.

The Android entries link to the real [Derivify calculator screenshot](https://github.com/codewithmahad/Derivify-Calculus-Toolkit/blob/master/screenshots/calculator.png) and [Quizzler feedback screenshot](https://github.com/codewithmahad/Quizzler-App/blob/master/screenshots/quiz_feedback.png). Their implementation links open the differentiation engine and quiz ViewModel respectively.
