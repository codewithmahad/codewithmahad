# Learning lab buttons

These buttons reuse the artwork shared by JAVA_LAB, DSA_LAB, SQL_LAB, and LINUX_LAB. The profile displays them at 32 pixels high for secondary navigation; contact buttons remain 40 pixels high. The SVGs retain their original 40-pixel viewports, solid backgrounds, centered icons, and outlined Segoe UI Semibold labels. They have no external font dependencies.

- **Java:** [Devicon Java geometry](https://github.com/devicons/devicon/blob/master/icons/java/java-original.svg), adapted to Java.com blue and orange on white.
- **DSA:** original tree artwork, with black branches and orange nodes on pale amber.
- **SQL:** the original [Devicon PostgreSQL elephant](https://github.com/devicons/devicon/blob/master/icons/postgresql/postgresql-original.svg) on blue.
- **Linux:** unchanged **Tux, by Larry Ewing, created using The GIMP**, on silver. [Original artwork and reuse terms](http://isc.tamu.edu/~lewing/linux/) ? [LINUX_LAB source notes](https://github.com/codewithmahad/LINUX_LAB/blob/main/assets/README.md#tux).

The [Devicon MIT notice](DEVICON-LICENSE.txt) covers the Java and PostgreSQL source artwork. Third-party marks retain their respective ownership and terms. These SVGs are maintained directly and are not regenerated by the profile build.
