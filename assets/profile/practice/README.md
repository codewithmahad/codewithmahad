# Platform assets

These original assets are used by the current profile or embedded into its contact buttons. Their colors and proportions are preserved.

| File | Original source | Use |
| :--- | :--- | :--- |
| `leetcode-original.png` | [LeetCode icon](https://assets.leetcode.com/static_assets/public/icons/favicon-192x192.png) | Source mark for the LeetCode button |
| `codolio-original.svg` | [Codolio logo](https://codolio.com/codolio_assets/codolio.svg) | Source mark for the Codolio button |
| `monkeytype-monkey.png` | [Monkeytype typing monkey](https://github.com/monkeytypegame/monkeytype/blob/master/frontend/static/images/monkey/m1_fast.png) | Illustration beside the typing note |

The Monkeytype illustration is unchanged and retains its upstream [GNU GPL v3 license](MONKEYTYPE-LICENSE.txt). Platform marks retain their respective ownership and terms. They identify linked profiles and do not imply endorsement.

## Typing illustration placement

`monkeytype-typing-layout.svg` embeds the unchanged Monkeytype PNG with transparent space above it. It is generated by [typing-illustration.mjs](../../../scripts/profile/typing-illustration.mjs) and included in the normal artwork build. The README uses a 16%-wide, 160-pixel-high viewport; the SVG preserves the original proportions and supplies spacing that GitHub retains. The original file and upstream license remain alongside it.

## Custom profile shortcut

`monkeytype-profile-inline.svg` is generated by [build.mjs](../../../scripts/profile/build.mjs), using original keyboard geometry and outlined Manrope lettering. Its charcoal-and-yellow palette is inspired by Monkeytype. It is a custom shortcut, not an official platform asset.

The 160 × 20 canvas fits inline with the typing paragraph. The README uses text-top alignment, zero horizontal image margin, and a narrow space before the button. The typing history is supplied by the owner: starting in 2023 at around 60 WPM and progressing to 130+ WPM.

The current HackerRank contact button uses Manrope lettering and a green terminal square; it does not depend on an original wordmark file.
