# Practice illustrations

All files in this folder are local SVGs. They contain no external images, fonts,
scripts, or network requests. Rebuild them with `buildPracticeAssets()` from
[`scripts/profile/practice.mjs`](../../../scripts/profile/practice.mjs).

| Files | Source |
| :--- | :--- |
| `keyboard-light.svg`, `keyboard-dark.svg` | Original vector keyboard illustration with a yellow escape key. This is not the Monkeytype logo. |
| `leetcode.svg`, `hackerrank.svg`, `geeksforgeeks.svg` | Glyphs extracted unchanged from the corresponding existing files in [`assets/socials`](../../socials/). The white glyphs and existing brand accent colors are preserved. |
| `progress.svg` | Original code and progress symbol used beside the Codolio link. This is not a Codolio logo. |

The platform marks identify links to Mahad's profiles. They remain the property
of their respective owners and are excluded from this repository's claim of
original artwork. Their presence does not imply endorsement or affiliation.
