# Contact buttons

The six buttons used in the profile are generated by [build.mjs](../../../scripts/profile/build.mjs). They share a 40-pixel height, rounded corners, and outlined Manrope lettering. The main README supplies destinations and accessible link names.

| File | Appearance |
| :--- | :--- |
| `portfolio-card.svg` | Light surface, blue M, black mahad and gray .dev |
| `linkedin-brand.svg` | LinkedIn blue with the original glyph and white lettering |
| `mail-brand.svg` | Warm red with an original white envelope and white lettering |
| `leetcode-brand.svg` | Graphite with the original LeetCode mark |
| `hackerrank-brand.svg` | Deep green with white lettering and a green terminal square |
| `codolio-brand.svg` | Orange with the original Codolio mark and white lettering |

LinkedIn’s source glyph is kept in [source/linkedin.svg](../source/linkedin.svg). LeetCode and Codolio source marks are retained in [practice/](../practice/). The portfolio mark, envelope, and button frames are custom SVG geometry; brand marks retain their respective ownership.

The labels use Manrope at the shared label weight, with stronger lettering for the portfolio name. Font files and notices remain in [source/](../source/). The buttons contain no live statistics, scripts, or external font dependencies.
