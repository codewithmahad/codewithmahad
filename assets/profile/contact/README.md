# Contact links

These small SVG links are built locally by [`build.mjs`](../../../scripts/profile/build.mjs). They use outlined Manrope lettering and transparent backgrounds in light and dark versions. The README supplies the actual destinations and accessible link names; no interaction is embedded in an image.

- **LinkedIn:** the brand glyph preserved in [`source/linkedin.svg`](../source/linkedin.svg), shown in LinkedIn blue with white lettering. The mark belongs to its respective owner and is excluded from this repository's original-artwork claim.
- **Portfolio:** an original browser-window icon in violet.
- **Email:** an original envelope icon with a small gold accent.

The icon and lettering layouts are generated as SVG, without image generation or an external badge service. Font licenses are retained in [`../source/`](../source/).
